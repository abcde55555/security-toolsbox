# Agent 会话 UX 演进路线（布局割裂问题评估）

> 背景：用户反馈①「Agent 输出在底部折叠面板，人工操作步骤却在上面」②「系统割裂，看不懂完整评估流程」。

## 现状诊断

| 区域 | 内容 | 问题 |
| --- | --- | --- |
| 主区 PhaseTimeline | 按四阶段分组的工具调用/人工步骤时间线 | 对话式回复被挤到底部折叠面板，因果叙事断裂 |
| 底部「工作上下文」 | 统计概览 + 模型交互明细 | 明细（真正的对话）藏在最不显眼的位置 |
| 项目详情 Tabs | 流程/变量/终端/审计/报告 | 与 Agent 会话互相独立，入口分散 |
| 全局导航 | 工具/模板/项目/Agent/知识库… | 缺少"我现在该做什么"的引导层 |

## 目标形态：对话中心式统一事件流

```
┌────────────────────────────────┐
│ AssessmentStepper（项目级五步） │ ← v0.8 已落地
├────────────────────────────────┤
│ 统一事件流（主区，按时间交织）：   │
│  💬 用户消息 / 💭 思考(灰) / 🤖 回复 │
│  🔧 工具卡（默认折叠）            │
│  🙋 人工步骤卡（内嵌在流中，带待办角标）│
│  ⚖ 判定草案卡                    │
├────────────────────────────────┤
│ 输入框（固定底部）                │
└────────────────────────────────┘
侧栏：阶段锚点 + 跨会话人工待办清单
```

## 分期与难度

| 期 | 内容 | 难度 | 说明 |
| --- | --- | --- | --- |
| **P1 统一事件流** | 新 EventStream 渲染器按 `events` 时间序交织消息/工具/人工/判定卡，替换 PhaseTimeline 主区；输入框上移为对话式 | 中（1–2 天） | 数据已齐备（events 含全部类型+seq），纯前端重排；人工卡的证据上传逻辑原样内嵌 |
| **P2 引导层收口** | 底部统计并入页头 Stepper；Agent 会话列表支持项目过滤；待办徽标升级为可展开清单（跳转+高亮对应卡） | 低（半天） | 待办 API `/api/agent/human-todos` 已就绪 |
| **P3 报告闭环内嵌** | 判定审核动作（approve/reject）直接在事件流内完成；报告摘要卡嵌入会话尾部 | 中（1 天） | 复用 VerdictReviewPanel |

## 已在本轮落地的相关项

- 项目详情页顶部 `AssessmentStepper`（准备→采集→Agent→审核→报告，点击跳转）
- 侧边栏「Agent 测试」红色徽标 = 跨会话人工待办数（15s 轮询）
- 富文本证据编辑器（文字+截图混排，粘贴即传）

## 触发 P1 的建议时机

当前交互可用性尚可（阶段分组清晰、人工卡有脉冲提醒+标题闪烁）。建议在下一次功能迭代窗口启动 P1——它是对话体验的质变点，也是消除"割裂感"的核心一刀。
